# Blockhost — локальная панель Minecraft

Веб-панель для установки и управления одним Minecraft-сервером на этом компьютере. Настройки и файлы сервера хранятся в `.host-data/`.

## Запуск

Нужны Node.js 20+ и Java, подходящая выбранной версии Minecraft. В корне проекта:

```sh
npm start
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Панель намеренно привязана к `127.0.0.1`: в ней есть управление процессом Java и консоль, поэтому не публикуйте её в интернете или общей сети без отдельной аутентификации и защиты.

## Возможности

- Установка последних сборок Paper, Purpur и Fabric по доступным версиям или загрузка собственного `server.jar`.
- Управление памятью Java, портом, MOTD, режимом игры, сложностью, миром, дальностью симуляции и прорисовки, whitelist, PvP и дополнительными `server.properties`.
- Профили оптимизации мира и JVM с G1GC; профиль также настраивает дальность сущностей.
- Поиск плагинов Paper/Purpur и Fabric-модов в Modrinth. CurseForge доступен после настройки API-ключа.
- Ручная загрузка JAR-файлов, список и удаление установленных плагинов и модов.
- Запуск и штатная остановка Java-процесса, ввод команд и просмотр/скачивание журнала.

Моды устанавливаются в Fabric-ядро; Paper/Purpur предназначены для плагинов. Проверьте совместимость ядра, загрузчика и каждого дополнения. Загрузка серверных JAR-файлов выполняется на свой риск.

Перед запуском нужно прочитать и принять [Minecraft EULA](https://aka.ms/MinecraftEULA) в настройках панели. Ядро не стартует, пока это подтверждение не сохранено.

## CurseForge

Получите API-ключ в CurseForge for Studios и задайте его только в окружении процесса, не в файлах проекта:

```sh
export CURSEFORGE_API_KEY='ваш-ключ'
npm start
```

Ключ не сохраняется панелью. Без него поиск Modrinth продолжает работать.

## Данные и сеть

- Конфигурация, ядро, плагины, моды и журнал находятся в `.host-data/` и исключены из Git.
- Для загрузки сборок и каталогов требуется исходящий доступ к API PaperMC, Purpur, Fabric, Modrinth и, при настройке, CurseForge.
- Игроки подключаются к Minecraft-серверу по указанному игровому порту. Внешний доступ к самой панели не нужен.
